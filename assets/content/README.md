# Portfolio content (edit these files)

All portfolio text lives here — no backend needed.

```
assets/content/
  en/   ← English
  ar/   ← Arabic
```

| File | What to edit |
|------|----------------|
| `profile.json` | Name, title, about summary, contact links |
| `experiences.json` | Jobs / roles and bullet highlights |
| `projects.json` | Project titles, descriptions, links, images |
| `skills.json` | Skill names and categories |
| `educations.json` | Degrees and schools |
| `certifications.json` | Certificates |
| `languages.json` | Spoken languages |

After editing, hot restart the app (`R` in the terminal).

Keep the same `id` values in EN and AR so both languages stay in sync.
